# Sensor Calibration Lab · 传感器标定实验台

一个用于学习传感器**线性标定分析**的本地工具。导入参考量与传感器输出的 CSV，查看正向标定曲线、残差和重复测量的重复性，并导出包含原始数据的可复现分析结果。

项目使用 **Python 3.9+ 标准库和原生浏览器界面，零第三方依赖**。适合练习测量数据处理、理解线性模型和比较重复测量结果；不是计量认证工具。仓库附带的数据全部为明确标记的合成数据，不代表真实实验、硬件性能或个人实验成果。

当前版本为 **1.0.1**，修复大跨度数据的数值计算、非 UTF-8 终端输出和命令行复算导出。各版本实际完成的检查见 [验证记录](docs/VALIDATION.md)。

## 启动

先安装 Python 3.9 或更新版本，并完整下载或克隆本项目。解压后进入包含 `app.py` 的项目目录；无需运行 `pip install`。

### Windows

在项目目录打开 PowerShell，运行：

```powershell
py -3 --version
py -3 app.py
```

如果电脑没有 `py` 启动器，但 `python --version` 显示 Python 3.9+，可使用 `python app.py`。下文中的所有 `py -3` 也可替换为 `python`。

也可双击 `launch.bat`，或在 PowerShell 中运行 `./launch.bat`。脚本会进入其所在目录，依次尝试可用的 `py -3` 和 `python`；不会安装依赖或修改系统配置。

### macOS / Linux

```sh
python3 app.py
```

也可运行 `sh launch.command`；脚本从其所在目录启动，不要求调整文件执行权限。

### 打开页面

在浏览器打开 <http://127.0.0.1:8765>。在终端按 `Ctrl+C` 停止服务。

服务默认使用本机地址 `127.0.0.1:8765`，不需要账号、API 密钥或云服务。CSV 在浏览器和本机 Python 服务之间处理，不发送到外部服务。

若端口已占用，可在启动命令末尾加 `--port 8766`，再打开 <http://127.0.0.1:8766>。启动脚本也接受这个参数。

1.0.0 的 Windows Python 3.9/3.13 自动化测试及 `launch.bat --help` 已在 GitHub Actions 通过；1.0.1 的新一轮跨平台 CI 尚待确认。Windows 图形界面尚未人工验证。[按版本查看验证记录](docs/VALIDATION.md)

命令行保留终端原有编码。若终端只能显示 ASCII 或 cp1252 等字符集，无法表示的中文会显示为 `\uXXXX` 等转义，避免因打印提示而崩溃；导出文件仍使用 UTF-8，不受终端编码影响。

## 用一次合成数据认识标定

1. 在页面加载合成示例，或导入 [`examples/synthetic_temperature.csv`](examples/synthetic_temperature.csv)。
2. 选择参考列 `reference_temperature_c` 和输出列 `sensor_output_v`。
3. 将参考单位填为 `°C`，输出单位填为 `V`。`repeat` 只是示例中的重复序号，不参与拟合或分组。
4. 执行分析，查看散点与拟合直线、残差图，以及各参考档位的重复性。
5. 导出 JSON 分析包、逐点结果 CSV 或可打印的 HTML 报告。

示例为 6 档参考温度、每档 3 次，共 18 个确定性合成观测。生成方法公开在 [`examples/README.md`](examples/README.md)，可运行下面的命令验证仓库内的数据是否与生成公式一致：

```sh
python3 examples/generate_example.py --check
```

Windows PowerShell 使用 `py -3 examples/generate_example.py --check`。

不带 `--check` 时，脚本会重新生成 `examples/synthetic_temperature.csv`。

## 导入自己的 CSV

CSV 必须有表头，至少有两列可作为参考量 `x` 和传感器输出 `y`。程序支持 UTF-8 文本（含 BOM），自动识别逗号、制表符或分号分隔；选中的数值列需要使用点号作为小数点。

```csv
reference_temperature_c,sensor_output_v,repeat
0,0.496000,1
0,0.501000,2
0,0.503000,3
```

以上片段也来自合成示例。分析至少需要 3 对有效观测，以及 2 个不同的参考值。表头不能为空或重复，各记录列数必须一致。界面文件上限为 1 MiB，单次最多读取 20,000 条数据记录、50 列；HTTP 请求体上限为 2 MiB，JSON 编码也会占用空间。超过 2,000 个有效点时，图形均匀采样显示，统计和导出仍使用全部有效数据。

选中列中的空值、非数值、非有限值或绝对值大于 `1e100` 的数值会被排除，并列出原因和 CSV 原始行号。非零文本若过小而在解析时下溢为零，也会被排除，不会静默当作真实零值。不会自动删除离群点。带换行的引号字段，其行号指该记录结束的物理行。空白记录忽略。

**单位仅作标签，不做换算。** 例如把 `mV` 改成 `V` 不会将数据除以 1,000；请先在源数据中完成换算，再填写实际单位。斜率单位是「输出单位 / 参考单位」，截距、残差和重复性指标使用输出单位。

## 如何解释结果

拟合使用所有有效观测进行普通最小二乘（OLS）正向回归：

```text
传感器输出 y = 斜率 a × 参考量 x + 截距 b
拟合值 ŷᵢ = a × xᵢ + b
残差 eᵢ = yᵢ − ŷᵢ
```

每个有效观测具有相同权重，因此重复次数更多的参考档位在拟合中占比更高。程序不先取各档均值再拟合，也不执行加权回归。

1.0.1 先将输入解析为二进制浮点数，再用这些数值的精确有理数表示计算 OLS、残差、平方和及分组统计，开平方时使用 80 位精度的十进制计算。各输出字段最后分别舍入为浮点数，避免大跨度数据在中间步骤丢失较小的偏差。**这不能恢复输入文本首次转换为浮点数时已经丢失的十进制信息。** 如果非零计算结果溢出或下溢到无法表示，分析会明确失败，并提示调整数量级或单位。

拟合参数、拟合值和残差各自独立舍入，因此用页面显示的已舍入参数重算，不一定逐位等于导出的残差。可复算结果应使用原始 CSV 与相同版本的程序。

设有效观测数为 `n`，`SSE = Σeᵢ²`，`SST = Σ(yᵢ − ȳ)²`：

| 指标 | 定义 | 解读 |
| --- | --- | --- |
| 斜率 `a` | `Σ(xᵢ − x̄)(yᵢ − ȳ) / Σ(xᵢ − x̄)²` | 每增加一单位参考量，拟合输出的变化量 |
| 截距 `b` | `ȳ − a × x̄` | 模型在参考量为零时的输出；零点不在测量范围内时属于外推 |
| 决定系数 `R²` | `1 − SSE / SST` | 描述模型对当前输出变化的解释程度；输出恒定时不定义 |
| 残差均方根 `RMSE` | `√(SSE / n)` | 当前数据相对拟合直线的均方根偏差 |
| 残差标准差 | `√(SSE / (n − 2))` | 估计斜率和截距后，使用 `n − 2` 个自由度 |
| 最大绝对残差 | `max(绝对值(eᵢ))` | 当前数据中最大的拟合偏差 |

残差应结合曲线形态来看：弯曲趋势可能提示线性模型不足，随参考值变大的散布可能提示方差不恒定。高 `R²` 本身不能证明传感器准确、模型适用或标定已通过验证；上述指标也不是相对于独立真值的准确度评定。

### 重复测量与重复性

程序仅将**解析后的参考数值完全相同**的观测放在同一组，例如 `10` 和 `10.0` 会合并；不会按四舍五入或近似值自动归组。

对组 `g`，设样本数为 `n_g`、输出均值为 `ȳ_g`：

```text
组内样本标准差 s_g = √[Σ(y_gj − ȳ_g)² / (n_g − 1)]
合并重复性标准差 s_p = √[Σ_g Σ_j(y_gj − ȳ_g)² / Σ_g(n_g − 1)]
```

组内标准差至少需要 2 次观测。单次观测组不提供重复性自由度；没有任何重复组时，合并重复性显示为未定义，而不是零。合并值按各组自由度加权，单位与传感器输出相同。

数值相同只是程序的分组规则。要把组内散布解释为实验重复性，还需由实验设计保证设备、方法、环境和短时间测量条件可比；程序无法从 CSV 确认这些条件。重复性不等于测量不确定度、准确度或参考标准的不确定度。

### 模型前提和适用范围

正向 OLS 将参考量 `x` 视为固定且误差可忽略，拟合输出方向的偏差。常见的统计解释还假定残差均值为零、观测独立且输出误差方差相近。参考量误差不可忽略、明显非线性或不同档位噪声差异较大时，需要另选模型或方法。

本工具不计算不确定度预算、置信区间或计量溯源结论，也不替代独立验证。不要把对这份数据的拟合直接当成在量程之外的有效标定。

## 导出与复算

- **JSON 分析包**：包含原始 CSV 文本、源文本 SHA-256、所选列与单位、应用版本、生成时间及全部分析结果。保留该文件可知道本次结果使用了哪份输入和设置。SHA-256 用于识别输入文本，不是数字签名或认证证明。
- **结果 CSV**：包含每个有效观测的参考量、输出、拟合值、残差及源行号，便于继续绘图或计算。
- **HTML 报告**：用于浏览器查看、打印或另存为 PDF，汇总本次标定结果。可复算的原始输入以 JSON 分析包为准。

JSON 包含**完整原始 CSV**，包括未选中的列和被排除的记录；分享前请检查其中是否含有不打算公开的信息。

可在项目目录使用命令行复算导出的 JSON，将文件名替换为实际导出路径。路径含空格时保留引号。

Windows PowerShell：

```powershell
py -3 app.py --replay "calibration-analysis.json"
py -3 app.py --replay "calibration-analysis.json" --output "recomputed-analysis.json"
```

macOS / Linux：

```sh
python3 app.py --replay "calibration-analysis.json"
python3 app.py --replay "calibration-analysis.json" --output "recomputed-analysis.json"
```

`--replay` 核对原始 CSV 的 SHA-256，并按包内设置重新分析。原报告与当前应用版本相同时，还逐值核对分析结果；输入或结果不一致会以错误退出。版本不同则重新计算并提示，不要求结果与旧版完全一致。**1.0.0 报告在 1.0.1 中按新版算法复算，不强制逐位等于旧版结果。** 原始报告仍应保留。

不加 `--output` 只复算，不创建文件；加上该参数会另存为新 JSON，**拒绝覆盖已存在的文件**。程序先完整生成 UTF-8 内容，再写入同目录临时文件并提交；序列化、写入或提交失败不会留下半截目标文件，已有目标保留。提交成功但临时文件清理失败时会给出警告。macOS / Linux 的提交需要目标目录所在文件系统支持硬链接，不支持时明确报错，可另选本机支持的目录。该流程保证运行时的提交完整性，不承诺断电后的持久性。

复算不启动网页服务。导出包的生成时间会随复算改变，分析结果由输入、设置和应用版本决定。
